# Casos de Prueba | Gestión de Prórrogas

## ID caso de prueba
CP-PROR-002

## Título de la prueba
Acceder a la opción "Añadir Prórroga"

## Módulo / Característica
Gestión de Prórrogas - Navegación

## Descripción
Verificar que el usuario pueda acceder a la opción para añadir una prórroga o adición.

## Precondiciones
- Usuario autenticado.
- Existe un contrato activo.

## Pasos para la ejecución
1. Acceder al contrato activo.
2. Hacer clic en "Añadir Prórroga / Adición".

## Resultado esperado
- El sistema muestra el formulario para registrar la prórroga.
