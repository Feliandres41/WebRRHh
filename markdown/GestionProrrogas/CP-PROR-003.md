# Casos de Prueba | Gestión de Prórrogas

## ID caso de prueba
CP-PROR-003

## Título de la prueba
Registro de prórroga por tiempo

## Módulo / Característica
Gestión de Prórrogas - Registro

## Descripción
Verificar que el sistema permita registrar una prórroga de tiempo en un contrato.

## Precondiciones
- Usuario autenticado.
- Usuario en el formulario de prórroga.

## Pasos para la ejecución
1. Seleccionar tipo "Tiempo".
2. Ingresar nueva fecha de finalización.
3. Guardar.

## Resultado esperado
- El sistema registra la prórroga.
- Se actualiza la fecha final del contrato.
