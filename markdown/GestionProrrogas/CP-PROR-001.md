# Casos de Prueba | Gestión de Prórrogas

## ID caso de prueba
CP-PROR-001

## Título de la prueba
Localizar contrato activo

## Módulo / Característica
Gestión de Prórrogas - Consulta

## Descripción
Verificar que el usuario pueda localizar un contrato activo para aplicar una prórroga.

## Precondiciones
- Usuario autenticado.
- Existe un contrato activo en el sistema.

## Pasos para la ejecución
1. Iniciar sesión en el sistema.
2. Acceder a la sección de contratos.
3. Buscar un contrato activo.

## Resultado esperado
- El sistema muestra la información del contrato activo.
