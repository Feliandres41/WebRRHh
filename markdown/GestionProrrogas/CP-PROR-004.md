# Casos de Prueba | Gestión de Prórrogas

## ID caso de prueba
CP-PROR-004

## Título de la prueba
Registro de adición de valor

## Módulo / Característica
Gestión de Prórrogas - Registro

## Descripción
Verificar que el sistema permita registrar una adición de valor al contrato.

## Precondiciones
- Usuario autenticado.
- Usuario en el formulario de prórroga.

## Pasos para la ejecución
1. Seleccionar tipo "Valor".
2. Ingresar valor de la adición.
3. Guardar.

## Resultado esperado
- El sistema registra la adición de valor.
- El contrato se actualiza correctamente.
