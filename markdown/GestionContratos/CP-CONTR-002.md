# Casos de Prueba | Gestión de Contratos

## ID caso de prueba
CP-CONTR-002

## Título de la prueba
Visualización de contratos asociados a un colaborador

## Módulo / Característica
Gestión de Contratos - Consulta

## Descripción
Verificar que el sistema muestre correctamente los contratos asociados a un colaborador.

## Precondiciones
- Usuario autenticado.
- El colaborador tiene contratos registrados.

## Pasos para la ejecución
1. Acceder al perfil del colaborador.
2. Seleccionar la pestaña "Contratos".

## Resultado esperado
- El sistema muestra una lista de contratos del colaborador.
- Cada contrato muestra información básica (tipo, fecha inicio, fecha fin, salario).

No ejecutado
