# Casos de Prueba | Gestión de Contratos

## ID caso de prueba
CP-CONTR-004

## Título de la prueba
Creación de un contrato para un colaborador

## Módulo / Característica
Gestión de Contratos - Registro

## Descripción
Verificar que el sistema permita registrar correctamente un contrato.

## Precondiciones
- Usuario autenticado.
- Usuario ubicado en el formulario de nuevo contrato.

## Pasos para la ejecución
1. Ingresar tipo de contrato.
2. Ingresar fecha de inicio.
3. Ingresar fecha de finalización.
4. Ingresar cargo.
5. Ingresar salario.
6. Guardar el contrato.

## Resultado esperado
- El sistema guarda el contrato correctamente.
- El contrato queda asociado al colaborador.
