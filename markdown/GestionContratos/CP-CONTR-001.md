# Casos de Prueba | Gestión de Contratos

## ID caso de prueba
CP-CONTR-001

## Título de la prueba
Acceso a la pestaña "Contratos" desde el perfil del colaborador

## Módulo / Característica
Gestión de Contratos - Navegación

## Descripción
Verificar que el usuario pueda acceder a la pestaña de contratos dentro del perfil de un colaborador.

## Precondiciones
- Usuario autenticado.
- Existencia de al menos un colaborador registrado.

## Pasos para la ejecución
1. Iniciar sesión en el sistema.
2. Acceder al perfil de un colaborador.
3. Seleccionar la pestaña "Contratos".

## Resultado esperado
- El sistema muestra la sección de contratos del colaborador.
- No se presentan errores.
