# Casos de Prueba | Gestión de Contratos

## ID caso de prueba
CP-CONTR-003

## Título de la prueba
Acceso al formulario "Nuevo Contrato"

## Módulo / Característica
Gestión de Contratos - Creación

## Descripción
Verificar que el usuario pueda acceder al formulario para crear un nuevo contrato.

## Precondiciones
- Usuario autenticado.
- Usuario ubicado en la pestaña "Contratos" del colaborador.

## Pasos para la ejecución
1. Ir al perfil del colaborador.
2. Ir a la pestaña "Contratos".
3. Hacer clic en "Nuevo Contrato".

## Resultado esperado
- El sistema muestra el formulario para registrar un contrato.
