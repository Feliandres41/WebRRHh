# Casos de Prueba | Terminación de Contratos

## ID caso de prueba
CP-TERM-002

## Título de la prueba
Seleccionar opción de terminación anticipada

## Módulo / Característica
Terminación de Contratos - Acción

## Descripción
Verificar que el usuario pueda seleccionar la opción "Terminación Anticipada" para finalizar un contrato.

## Precondiciones
- Usuario autenticado.
- Existe un contrato activo.

## Pasos para la ejecución
1. Acceder al módulo de contratos.
2. Seleccionar un contrato activo.
3. Elegir la opción "Terminación Anticipada".

## Resultado esperado
- El sistema muestra el formulario para registrar la terminación del contrato.
