# Casos de Prueba | Terminación de Contratos

## ID caso de prueba
CP-TERM-003

## Título de la prueba
Solicitar fecha y motivo de terminación

## Módulo / Característica
Terminación de Contratos - Formulario

## Descripción
Verificar que el sistema solicite la fecha de terminación y el motivo de la terminación del contrato.

## Precondiciones
- Usuario autenticado.
- Se accedió a la opción de terminación anticipada.

## Pasos para la ejecución
1. Seleccionar la opción de terminación anticipada.
2. Visualizar el formulario de terminación.

## Resultado esperado
- El sistema solicita la fecha de terminación.
- El sistema solicita el motivo de la terminación.
