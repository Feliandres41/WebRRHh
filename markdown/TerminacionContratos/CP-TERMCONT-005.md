# Casos de Prueba | Terminación de Contratos

## ID caso de prueba
CP-TERM-005

## Título de la prueba
Actualizar estado del contrato

## Módulo / Característica
Terminación de Contratos - Actualización

## Descripción
Verificar que el sistema actualice el estado del contrato a "Terminado" y registre la información de terminación.

## Precondiciones
- El usuario confirmó la terminación del contrato.

## Pasos para la ejecución
1. Confirmar la terminación del contrato.

## Resultado esperado
- El estado del contrato cambia a "Terminado".
- El sistema guarda la fecha y el motivo de terminación.
