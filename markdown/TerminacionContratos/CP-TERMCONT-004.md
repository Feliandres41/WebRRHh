# Casos de Prueba | Terminación de Contratos

## ID caso de prueba
CP-TERM-004

## Título de la prueba
Confirmar terminación de contrato

## Módulo / Característica
Terminación de Contratos - Confirmación

## Descripción
Verificar que el usuario pueda confirmar la terminación del contrato después de ingresar la información solicitada.

## Precondiciones
- Usuario autenticado.
- Formulario de terminación visible.

## Pasos para la ejecución
1. Ingresar la fecha de terminación.
2. Ingresar el motivo de terminación.
3. Confirmar la acción.

## Resultado esperado
- El sistema procesa la solicitud de terminación del contrato.
