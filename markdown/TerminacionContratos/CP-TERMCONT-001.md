# Casos de Prueba | Terminación de Contratos

## ID caso de prueba
CP-TERM-001

## Título de la prueba
Localizar contrato activo

## Módulo / Característica
Terminación de Contratos - Consulta

## Descripción
Verificar que el usuario pueda localizar el contrato activo que desea terminar.

## Precondiciones
- Usuario autenticado.
- Existe al menos un contrato activo en el sistema.

## Pasos para la ejecución
1. Iniciar sesión en el sistema.
2. Acceder a la sección de contratos.
3. Buscar un contrato activo.

## Resultado esperado
- El sistema muestra la información del contrato activo.
